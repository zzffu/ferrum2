# Architecture decision records

Copy `ADR-0000-template.md` to the next numbered file. Accepted ADRs are contracts;
supersede them explicitly rather than editing history silently.

ADR-0016 distinguishes normative invariants from selected conformance profiles and
mechanical realization. Changing an invariant still requires an explicit ADR/spec
revision; an evidence-only substitution follows ADR-0016's pre-execution mapping
and review rules and must not be used as a waiver.
